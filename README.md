## 🏦 Desafios

### Sistema bancário com Python

Sistema bancário simples, executado no terminal, com um menu interativo e três operações:

- **Depósito**: aceita apenas valores positivos.
- **Saque**: limite de 3 saques diários e de R$ 500,00 por saque, com validação de saldo.
- **Extrato**: lista todas as movimentações e exibe o saldo atual no formato `R$ xxx.xx`.

Conceitos praticados: variáveis, estruturas condicionais, laço `while`, `input`, f-strings e formatação de números.

Para executar:

```bash
python desafio.py
```

> Ajuste o caminho do arquivo conforme o nome que ele tem dentro da pasta `Desafios`.

## 🚀 Como executar os códigos

1. Clone o repositório:

   ```bash
   git clone https://github.com/Erasmo-Jr/Suzano-Python-Developer.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd Suzano-Python-Developer
   ```

3. Execute qualquer arquivo com o Python instalado:

   ```bash
   python "caminho/do/arquivo.py"
   ```
