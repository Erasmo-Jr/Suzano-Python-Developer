# processamento_imagem

Pacote Python para processamento de imagens, desenvolvido como desafio de projeto da trilha **Suzano Python Developer** da [DIO](https://www.dio.me/).

## Funcionalidades

### Processamento
- Comparação de histogramas
- Similaridade de estruturas
- Redimensionamento de imagem

### Utilidades
- Carregar imagem
- Salvar imagem
- Exibir imagem
- Exibir resultados
- Exibir histograma

## Instalação

Clone o repositório e instale o pacote localmente com o [pip](https://pip.pypa.io/en/stable/):

```bash
git clone https://github.com/Erasmo-Jr/Suzano-Python-Developer.git
cd Suzano-Python-Developer/Desafios/04_desafio-pacote-processamento-imagem
pip install .
```

Ou instale só as dependências:

```bash
pip install -r requirements.txt
```

## Uso

```python
from processamento_imagem import ...  # importe aqui os módulos que você criou
```

> Ajuste o import conforme os nomes dos módulos do seu pacote.

## Sobre o projeto

O objetivo deste desafio foi aprender a **criar, estruturar e distribuir um pacote Python**, usando `setup.py`, `requirements.txt` e organização em módulos, aplicando conceitos de processamento de imagens.
